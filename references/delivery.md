# 可移动的交付目录

`delivery` 打包已完成的视频，不重新编码、不上传网站。先确认接收者的设备、是否离线，以及通过网盘还是网页观看；先交付一套并在目标设备播放，再扩大制作批次。

三种模式分别是：

| mode | 输出和用途 |
| --- | --- |
| `videos` | 按配置顺序命名的 MP4、说明及 manifest。适合网盘下载后用播放器观看。 |
| `offline` | MP4 子目录和静态 `index.html`，适合完整下载后的桌面浏览器。必须保留全部文件。 |
| `site` | 完整静态网站目录，由用户上传到 HTTP(S) 静态托管。命令不会发布。 |

`offline` 与 `site` 都有无需 JavaScript 的课程标题、MP4 链接、视频控件和章节列表。JavaScript 仅增强页内章节定位。相对资源链接可随整个目录移动；没有网络字体、CDN 或在线播放器依赖。

配置示例（MP4 路径相对于此配置文件）：

```json
{
  "title": "中文数学课程",
  "mode": "videos",
  "courses": [
    {
      "title": "A01 尖子生必备第1套",
      "file": "masters/A01.mp4",
      "chapters": [
        {"title": "读题", "start": 0},
        {"title": "讲解", "start": 12.5}
      ]
    }
  ]
}
```

`courses[].sha256` 可选，用于绑定事先审核过的原片。章节起点以秒为单位，必须递增且位于视频流的画面时长内；音频封装补齐不能扩大章节范围。manifest 分别保存 `media.videoDuration`、`media.containerDuration` 和视频时长来源，不用包含 AAC 尾部的容器时长代替画面边界。标题保持用户原文，仅输出文件名中的路径字符和系统保留字符被替换。源路径必须位于配置目录内，禁止 `..`、绝对路径和符号链接。

模块接口：`packageDelivery(configFile, {out, mode?})`。`out` 必须显式指定且不存在。验证全部输入后在临时目录组装，完成检查才移动到正式输出目录；失败清除本次临时目录，不覆盖现有目录。

`checkDelivery(directory)` 检查包内文件哈希、课程哈希、HTML 相对依赖、路径安全和每个视频的完整解码。包移动后不需要原课程工程。SHA256 是一致性检查，不是签名；若同时恶意修改 manifest 和媒体，需要外部保存的可信 manifest 哈希才能证明原始交付身份。

`delivery-manifest.json` 记录输入相对来源、输入与输出 SHA256、媒体属性、章节、兼容说明和审核状态。完整视频及音频解码证明技术可读，不能证明内容正确、数学正确、人工连续视听通过或目标设备兼容。后两项始终初始为 `UNREVIEWED`，不能因打包成功而升级。

| 环境 | 默认状态 | 验收要求 |
| --- | --- | --- |
| 桌面完整离线目录 | 预期支持 | 在接收设备打开目录、播放并跳转章节 |
| HTTP(S) 网站 | 预期支持 | 检查服务端媒体类型、实际播放及拖动跳转 |
| iPad 本地 HTML / PWA 离线 | 未知 | 没有实机证据；本包不是 PWA |
| 夸克等网盘 HTML 临时预览 | 不支持此交付方式 | 预览可能只复制 HTML，导致相对 MP4 不存在；改用纯视频或完整目录下载 |

只有记录具体设备、系统/浏览器、验证日期、播放和章节跳转结果后，才能在项目验收记录中写“已实测”。不要把桌面浏览器的成功当成 iPad 验收，也不要把网盘当作静态网站托管。
